### 改动 2：上架按钮乐观更新消除卡顿

**文件**：`src/pages/desktop/Products.tsx`（第 294-306 行）

**改动内容**：
将 `toggleShelfMutation` 改为乐观更新模式，直接修改缓存中对应产品的 `on_shelf` 字段，不触发全表 refetch：

```tsx
const toggleShelfMutation = useMutation({
  mutationFn: async ({ id, value }: { id: string; value: boolean }) => {
    const { error } = await supabase
      .from('products')
      .update({ on_shelf: value, updated_at: new Date().toISOString() })
      .eq('id', id)
    if (error) throw error
  },
  onMutate: async ({ id, value }) => {
    // 取消正在进行的 products 查询，避免乐观更新被覆盖
    await queryClient.cancelQueries({ queryKey: ['products'] })
    // 保存前一个快照用于回滚
    const previousData = queryClient.getQueryData(['products', search, categoryFilter, selectedTagFilter])
    // 乐观更新：直接修改缓存中对应产品的 on_shelf
    queryClient.setQueryData(
      ['products', search, categoryFilter, selectedTagFilter],
      (old: ProductWithTags[] | undefined) => {
        if (!old) return old
        return old.map((p) => (p.id === id ? { ...p, on_shelf: value } : p))
      },
    )
    return { previousData }
  },
  onError: (_err, _vars, context) => {
    // 回滚到之前的数据
    if (context?.previousData) {
      queryClient.setQueryData(
        ['products', search, categoryFilter, selectedTagFilter],
        context.previousData,
      )
    }
    toast.error('状态更新失败')
  },
  onSuccess: () => {
    // 不再 invalidate，避免全表 refetch
    // 静默更新即可，staleTime 会在后台自然刷新
  },
})
```

**关键点**：
- `onMutate`：在请求发出前，立即更新 UI 缓存 → 按钮瞬间响应
- `onError`：失败时回滚 → 数据一致性保障
- `onSuccess`：移除 `invalidateQueries`，不再触发全表 refetch
- 使用 `search`/`categoryFilter`/`selectedTagFilter` 当前值精确定位缓存 key

#### 3c. 分层视图实现
将库位按 `zone` → `rack` 二级分组：

```
A区
  ┌─ 01架 (15个库位, 8个已占用)  [折叠/展开]
  │   ├─ 01层: [库位卡片网格]
  │   ├─ 02层: [库位卡片网格]
  │   └─ ...
  └─ 02架 (12个库位, 5个已占用)  [折叠/展开]
      ├─ ...
B区
  └─ ...
```

每个库位以紧凑卡片展示：
- 库位编码（如 A-01-02-L3）
- 占用产品标签（产品名 ×数量）
- 空库位显示淡灰色"空"
- 悬停显示编辑/删除按钮

分组逻辑：
```tsx
// 将 locations 按 zone → rack 分组
const groupedLocations = useMemo(() => {
  const groups = new Map<string, Map<string, Location[]>>()
  for (const loc of locations || []) {
    const zone = loc.zone || '未分区'
    const rack = loc.rack || '未编号'
    if (!groups.has(zone)) groups.set(zone, new Map())
    const rackMap = groups.get(zone)!
    if (!rackMap.has(rack)) rackMap.set(rack, [])
    rackMap.get(rack)!.push(loc)
  }
  return groups
}, [locations])
```

#### 3d. 平铺视图
